# Entrega 03 - Proyecto Final

Entrega final del proyecto "Sistema de Evaluación y Clasificación de Riesgo Crediticio mediante R".

Esta entrega integra el desarrollo completo del proyecto, incluyendo la descripción y planificación de la solución,
el Producto Mínimo Viable (MVP), la documentación del proceso, limpieza y transformación de datos, evaluación del modelo, 
propuesta de despliegue y monitoreo.

El proyecto utiliza un modelo de regresión logística desarrollado en R para estimar la probabilidad de dificultades financieras y
generar información de apoyo para la evaluación de riesgo crediticio.
