# Entrega 01 - Descripción y Planificación

Primera entrega del proyecto "Sistema de Evaluación y Clasificación de Riesgo Crediticio mediante R".

Esta entrega contiene la descripción de la solución propuesta, el problema de negocio, objetivo, 
usuarios e impacto, fuente de datos, periodicidad y alcance del proyecto.

Además, incorpora la planificación del trabajo y Carta Gantt para el desarrollo de las distintas etapas del proyecto.
