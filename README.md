# Sistema de Evaluación y Clasificación de Riesgo Crediticio mediante R

Proyecto desarrollado para el curso **Finanzas en R**, orientado al desarrollo de una 
herramienta de evaluación y clasificación de riesgo crediticio que permita analizar información 
financiera y antecedentes de comportamiento crediticio para apoyar la toma de decisiones.

## Estructura del repositorio

### Entrega 01 - Descripción y Planificación

Contiene la descripción del problema y de la solución propuesta, fuente de datos, objetivo general,
usuarios e impacto de la solución, forma de abordar el problema, periodicidad y alcance del proyecto.

Además, incorpora la planificación del trabajo y la Carta Gantt con las distintas etapas consideradas
para el desarrollo del proyecto.

### Entrega 02 - Producto Mínimo Viable (MVP)

Contiene el desarrollo del Producto Mínimo Viable del sistema de evaluación y clasificación de riesgo
crediticio mediante R, incluyendo el código desarrollado, la base de datos utilizada y los archivos necesarios 
para la reproducibilidad del proyecto.

### Entrega 03 - Proyecto Final

Contiene la versión final e integrada del proyecto, incorporando la descripción y planificación de la solución, el Producto Mínimo Viable (MVP), 
la documentación del proceso, limpieza y transformación de datos, evaluación del modelo, Model Card, propuesta de despliegue y monitoreo.

Además, incluye el informe final, código desarrollado en R, base de datos utilizada, visualizaciones de resultados y los archivos necesarios para la
reproducibilidad del proyecto.

## Fuente de datos

Para el desarrollo del proyecto se utiliza la base de datos **Give Me Some Credit**, trabajando principalmente
con el archivo `cs-training.csv`.
